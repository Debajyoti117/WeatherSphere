# 🌦️ WeatherSphere

A modern weather application built with React, TypeScript, and WeatherAPI.

## Features

- 🌍 Search weather for any city
- 📅 7-Day Forecast
- 🌡️ Real-time Temperature
- 💨 Wind Speed & Direction
- 💧 Humidity
- 🌅 Sunrise & Sunset
- 🌫️ Air Quality Index (AQI)
- ✨ Glassmorphism UI
- 📱 Responsive Design

## Tech Stack

- React
- TypeScript
- Vite
- WeatherAPI
- Axios
- Vercel
